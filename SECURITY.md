# Security Policy

## Supported versions

At this stage, security fixes are applied to the latest `main` branch.

## Reporting a vulnerability

Please do not open public issues for security vulnerabilities.

Instead, report privately with:

- A clear description of the issue
- Reproduction steps or proof of concept
- Potential impact
- Suggested mitigation (if available)

If GitHub Security Advisories are enabled for this repository, use the
"Report a vulnerability" flow. Otherwise, contact the maintainers directly.

We will acknowledge receipt quickly and work with you on remediation and
responsible disclosure timing.
